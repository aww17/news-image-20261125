# The World in One Page — 25 November 2026

A single 1024 by 1024 newspaper front page that sums up the world news of Wednesday 25 November 2026.
`main.py` copies the pre-rendered `entry.png` (beside it) into the output directory named by `MAKEFUN_OUTPUT_DIR`,
or `/output` when unset, creating that directory if needed. Python 3.13 standard library only.

Entered in the make.fun bounty: https://make.fun/bounty/news-image-20261125

## The seven stories

1. **SPACE** — Shenzhou-24 lifts off with first foreign astronaut. (Reuters site reporting)
2. **NVIDIA** — Huang says he is in therapy. (Reuters site reporting)
3. **CHINA** — Shanghai pledges loyalty after probe. (SCMP)
4. **UNITED STATES** — Soldier admits selling secrets to China. (AP)
5. **UNITED NATIONS** — Five women killed every hour. (UN News / AFP)
6. **IRAN** — Rial hits record low. (Arab News / AFP)
7. **CRIME** — FBI smashes global fraud rings. (AP)

Sources: Reuters, SCMP, AP, AFP, UN News, Arab News.
